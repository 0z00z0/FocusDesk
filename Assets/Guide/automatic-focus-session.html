Automatic focus sessionAutomatisk fokusøkt

A Home Assistant automation can start a focus session at a set time. It makes three calls in order: the session type, the minutes, then the session switch.

En automasjon i Home Assistant kan starte en fokusøkt til et fast klokkeslett. Den gjør tre kall i rekkefølge: økttypen, minuttene og til slutt bryteren for økten.

Button and field names are given as Home Assistant 2026.10 shows them in English.

Navn på knapper og felt er gjengitt slik Home Assistant 2026.10 viser dem på engelsk.

1

Check that FocusDesk is in Home AssistantSjekk at FocusDesk finnes i Home Assistant

Open Settings › Devices & services › Devices and search for FocusDesk. The device is named FocusDesk followed by the PC's name. The automation uses the three marked entities.

Missing? Turn on the connection in FocusDesk's own settings, on the MQTT page.

Leave the Focus session switch alone here: turning it on starts a session at once.

Åpne Settings › Devices & services › Devices og søk etter FocusDesk. Enheten heter FocusDesk etterfulgt av PC-ens navn. Automasjonen bruker de tre merkede entitetene.

Mangler den? Slå på tilkoblingen i FocusDesks egne innstillinger, på MQTT-siden.

Ikke rør bryteren Focus session her: slås den på, starter en økt med en gang.

2

Create an automation with a time triggerLag en automasjon som starter på et klokkeslett

Open Settings › Automations & scenes › Create automation › Create new automation. Then choose Add trigger › Time and location › Time, keep Fixed time and enter the start time.

Only on some days: Add condition › Time and location › Time, and tick the weekdays.

Åpne Settings › Automations & scenes › Create automation › Create new automation. Velg så Add trigger › Time and location › Time, behold Fixed time og skriv inn starttidspunktet.

Bare enkelte dager: Add condition › Time and location › Time, og kryss av ukedagene.

3

Action one: the session typeHandling én: økttypen

Choose Add action, search for select option and choose Select option. As target, choose the entity Focus session type. Under Option, pick Program focus or Screen break.

The two option words stay in English, whatever language FocusDesk or Home Assistant runs in.

Velg Add action, søk etter select option og velg Select option. Velg entiteten Focus session type som mål. Under Option velges Program focus (programfokus) eller Screen break (skjermpause).

De to ordene står alltid på engelsk, uansett språk i FocusDesk og Home Assistant.

4

Action two: the minutesHandling to: minuttene

Choose Add action and Set number value. As target, choose Focus session minutes. Value is the length in minutes, from 1 to 240.

Velg Add action og Set number value. Velg Focus session minutes som mål. Value er lengden i minutter, fra 1 til 240.

5

Action three: turn the session onHandling tre: slå på økten

Choose Add action and Turn on switch, with the target Focus session.

Keep this action last. The session starts with the type and minutes it holds at that moment.

Velg Add action og Turn on switch, med Focus session som mål.

Denne handlingen står sist. Økten starter med typen og minuttene som er satt i det øyeblikket.

6

Save, and what happensLagre, og hva som skjer

Choose Save, give the automation a name, and choose Save again.

  • At the set time the session starts on the PC at once, with no focus-point window and no breathing exercise first.
  • It ends by itself when the minutes run out. Focus session remaining counts down in Home Assistant.
  • FocusDesk has to be running and connected to Home Assistant at that time.

Velg Save, gi automasjonen et navn og velg Save igjen.

  • Til fastsatt tid starter økten på PC-en med en gang, uten fokuspunktvinduet og pusteøvelsen først.
  • Den slutter av seg selv når minuttene er brukt opp. Focus session remaining teller ned i Home Assistant.
  • FocusDesk må kjøre og være koblet til Home Assistant på det tidspunktet.

Ending earlyAvslutte tidlig

Turning Focus session off does not end the session. It starts the staged cancel: a 5-minute wait, then a 10-second window in which turning it off again ends the session. Missed, the session runs to its own end. Nothing else ends it early.

Å slå av Focus session avslutter ikke økten. Det starter den trinnvise avbrytingen: fem minutters venting, deretter et vindu på ti sekunder der en ny avslåing avslutter økten. Går vinduet ubrukt, varer økten til sin egen slutt. Ingenting annet avslutter den tidlig.
